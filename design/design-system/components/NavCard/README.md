A large tappable tile linking to one section of the app: an emoji icon, a bold label and one line of description.

- `href`, `icon` (one emoji), `label`, `description`, `tone` `red` | `yellow`.
- Lay tiles out in a grid with `gap-5` (`grid-cols-1 sm:grid-cols-2 lg:grid-cols-3` on the home dashboard) and alternate red and yellow.
- It renders a real link (Next.js `Link`, a plain anchor outside the app).
