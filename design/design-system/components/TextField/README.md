A labelled single-line input with an optional error message under it.

- `label` (upper-cased label above; omit only when something else labels it, then pass `aria-label`), `error` (red border and message).
- Passes through every native input prop: `value`, `onChange`, `placeholder`, `type`, `defaultValue`, `autoComplete`.
- Stack fields with `gap-4`. Placeholders show a real example, often in Vietnamese ("xin chào").
